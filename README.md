# RegistrationForm

**RegistrationForm** — это веб‑форма регистрации пользователя, реализованная на чистом **HTML, CSS и JavaScript**.  
Проект показывает навыки валидации формы, взаимодействия с DOM и создании интерактивного пользовательского интерфейса.

## 🚀 Обзор

Это приложение позволяет пользователю:

- вводить имя, email и пароль;
- проверять корректность введённых данных в реальном времени;
- выводить сообщения об ошибках;
- отображать успех при правильной заполненной форме.

Цель проекта — показать навыки работы с формами, обработкой событий и базовой логикой валидации на стороне клиента.

---

## 🛠 Технологии

Проект использует:

- **HTML5** — структура страницы  
- **CSS3** — стили и оформление  
- **JavaScript (ES6+)** — логика валидации и работа с DOM
